# Gulf Coast Gig Guide

A static GitHub Pages demo. Open `index.html` through a web server or publish the repository with GitHub Pages.

## Files
- `index.html` — page structure
- `styles.css` — appearance
- `app.js` — show data and working filters
- `.nojekyll` — tells GitHub Pages to serve the files as-is

## Important
The current 122 listings are demonstration data used to test the interface. Verify all events with the venue before traveling.
